# 🌿 Ecosistema Sostenible — Guía Interactiva del Proyecto Capstone

Guía visual e interactiva que acompaña el **Proyecto Final de Programación 1** (Jala University): un simulador ecológico en Java basado en un autómata celular.

Esta página explica las reglas del ecosistema (actores, vecindarios, nacimientos, supervivencia, movimiento, parámetros CLI) y permite **probar un simulador en vivo en el navegador** antes de implementarlo en Java.

**[Abrir la guía interactiva →](https://zerchito.github.io/proyecto-capstone-ecosistema)**

> Reemplaza el enlace de arriba con la URL real una vez que actives GitHub Pages (ver abajo).

No necesitas instalar nada ni clonar el repositorio: solo abre el enlace desde cualquier navegador, computadora o celular.

## 📖 Qué incluye

- Descripción general del proyecto y los 4 actores del ecosistema (vacío, árbol, animal, agua).
- Explicación de los vecindarios inmediato y externo, con diagramas.
- Reglas de nacimiento, supervivencia y muerte de cada actor, **con animaciones** que muestran qué condición se cumple antes de transformar la celda.
- Reglas de movimiento animal sobre un mini tablero 3×3, incluyendo el caso de bloqueo por agua y por otro animal.
- Tabla completa de parámetros de línea de comandos (`w`, `h`, `g`, `s`, `n`, `m`) y ejemplos de validación.
- **Simulador interactivo**: ingresa los mismos parámetros que recibiría tu programa por consola y observa la evolución generación por generación.
- Preguntas frecuentes sobre errores comunes de implementación.

## ⚠️ Importante para estudiantes

El simulador de esta página es una **implementación de referencia independiente**, escrita en JavaScript solo para visualizar el comportamiento esperado del ecosistema. **No es, ni reemplaza, la solución en Java** que deben entregar como proyecto. Úsenla para comparar el comportamiento de su propio programa y resolver dudas sobre las reglas, no como código fuente a copiar.
